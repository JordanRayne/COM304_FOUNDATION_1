## Personal Notes and research following this session
Machine code
Machine code is a program that is written in binary so it only uses 1s and 0s. This makes it easy for computers to read the code because it matches the laguage of the precessor. Each machine code has instruction that tells the computer what tasks it can complete like adding numbers, and moving data from one place to another. Although machinecode is difficult for humans to read and understand, there are programers who use other codes to make machine code readable like assembly or hight languages to convert it.
Assembly code
Assembly code as already stated is better the machine code, becuase instead of using 1s and 0s it uses ADD (adding numbers) and MOV (moving data) also known as mnemonics. Assembly code is almost like machine code only assembly is easier for humans to read. Althoug it does still need to be changed into machine code before the computer is able to run it. But assembly still gives programers more control over the computer unlike the next topic High level languages.
High level programming languages 
Examples of high level languages is Python,Java, and C++. They are all made to be easier for humans to be able to read and write programs. THey do this by using words and symbols but even then highlevel languages still need to be written machine code this is achieved with compilers and/or interpreter. High level languages allow programmers to make more complex programs that are able to run faster they are also easier to debug and also understand.
Subroutines and Stack
Firstly subroutine it is a set of instructions that has to do a specific jon but can also be used more then once in aprogram. An example could be there could be a time you have to add a subroutine, this is called nesting. Nesting allows the computer to use the part of its memory called the stack, this helps keep track of where it has to go after the subroutine is done. this helps the program run more smoothly so it  dosent lose track of whats it is doing along the way
Interrupts
Interrupts uses a signal to tell a computer to basicly stop whatever it is and do somthing that is more impotant. An example is if someone pressed a key on an key board or was sent something from the internent that can trigger an interrupt. When that happens the computer leaves what it was doing for the time being and runs a code to work on the interrupt then after it completes that task it can go back. This basicly allows the computer to effectivly take on task when they show up instead of having to check every time
