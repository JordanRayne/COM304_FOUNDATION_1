# Council Proposal 6

## Explanation of this proposal
This proposal would make the council’s website and app the main way for the public to access services. People would go online first to submit forms, make payments, report issues, or find information.

How it might be implemented

Improve the website and app.  
Put most services online.  
Add one secure login.  
Train staff.  
Keep phone and in-person help for those who need it.

## Evaluation of the proposal
This proposal is a good idea because it makes services faster and more up-to-date. It can save money and make the council easier to use. However, the council must keep services simple and secure, ensuring that people who cannot use digital tools still receive assistance.
